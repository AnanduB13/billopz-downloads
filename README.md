# BillOPZ desktop downloads

This is the public distribution repository for BillOPZ by TENZTRO Private Limited. Application source code is maintained separately in a private repository.

## Availability

The first Windows installer has not been published yet. There is currently no installer to download here. A release will appear under [Releases](https://github.com/AnanduB13/billopz-downloads/releases) after its Windows build and release checks are complete.

## Windows support

The initial desktop installer targets Windows 10 and 11, 64-bit x64. Customers do not need Node.js or npm.

Initial releases may be unsigned. Windows may show **Windows protected your PC**. If you obtained the installer from a BillOPZ release here, choose **More info → Run anyway**, if offered. Keep Windows security settings enabled. Some security policies block unsigned applications; contact your administrator if installation is blocked.

Sign in online and wait for the counter to finish preparing before using offline POS billing. Other cloud features require an internet connection.

## Published release contents

- The versioned BillOPZ Windows Setup.exe installer.
- `SHA256SUMS.txt`, to verify the installer download.
- `INSTALL-WINDOWS.txt`, with installation and manual update instructions.

Use the **Setup.exe** release asset to install BillOPZ. GitHub's automatically generated **Source code** archives contain only the public files in this repository and are not the application installer.

Downloading an installer does not purchase a BillOPZ subscription. Product details and terms will be available at [the BillOPZ website](https://billopz-landing.netlify.app) when the production website launches.
